### Спільний шкільний зошит для вчителя та класу — у реальному часі

**ЦеЗошит** — це інтерактивна онлайн-дошка у форматі шкільного зошита: малювання від руки,
текст, фігури, стікери, зображення, таблиці, QR-коди, таймери, AI-помічник і, головне, —
**спільна робота вчителя та учнів одночасно**, з повним контролем прав вчителя.

Учитель готує урок як у звичайному зошиті, а на уроці клас пише й малює на одній сторінці:
усі бачать курсори одне одного, вчитель точково керує правами, проводить тест-опитування
та показує, хто що відповів.

## ✨ Можливості

**Зошит**
- 📄 Тетрадь на весь екран, «нескінченна лента сторінок» — нова сторінка створюється сама при гортанні вниз
- ✏️ Перо зі згладжуванням, фігури (прямокутник, овал, трикутник, лінія, стрілка, з заливкою)
- 🧹 Ластик — діє лише на власні об'єкти (учень не витре написане вчителем)
- 🔤 Текст: жирний, курсив, підкреслення, закреслення, над-/підрядковий, вирівнювання, друкований/рукописний шрифт
- 🖼 Вставка: зображення (файл, drag&drop, Ctrl+V), стікери 5 кольорів, таблиці з редактором, кругові таймери, QR-коди
- ↩️ Undo/Redo (Ctrl+Z / Ctrl+Shift+Z), автозбереження, експорт/імпорт `.json`, сторінка в PNG, друк/PDF
- 🔍 Масштаб колесом/пінчем, Ctrl+0 — «вписати сторінку»
- ⚙️ Формат сторінки: лінійка / клітинка / прописи / чистий лист

**Спільна робота (серверна версія)**
- 👥 Реальна синхронізація: десятки учнів в одній сесії, курсори з іменами й кольорами
- 🔐 Права вчителя: глобальний «лише перегляд», точкові заборони інструментів, блокування учня, кік, «ведучий» ⭐, «піднята рука» ✋
- 📊 **Тест-опитування класу**: питання + варіанти → всі відповіді → правильний варіант і хто який обрав
- 🔳 QR-код входу в клас — учні сканують телефоном і одразу в сесії
- 🕘 Снапшоти сторінок: «як було 5 хвилин тому», журнал подій
- 🔌 Автовідновлення з'єднання після обриву, вхід за посиланням `?join=КОД`

**AI-помічник ✨** (власний API-ключ, зберігається тільки у вашому браузері)
- 📝 Генератор контенту — одразу вставляє текст на сторінку
- 🔍 Перевірка орфографії — виділіть текст, AI виправить об'єкт
- 📊 Генератор тестів — AI придумує питання і одразу запускає опитування класу
- 🎤 Голосовий ввід (uk/ru/en)
- Провайдер визначається **автоматично за ключем**: OpenAI, Groq (безкоштовно), Google Gemini (безкоштовно), OpenRouter, DeepSeek; режим «Свій сервіс» для будь-яких OpenAI-сумісних API

## 🚀 Швидкий старт

### Варіант 1: локально, за 2 хвилини

```bash
git clone https://github.com/ВАШ_ЛОГІН/sovezoshit.git
# відкрийте файл подвійним кліком — усе працює офлайн:
xdg-open sovezoshit/local/index.html     # Linux
open sovezoshit/local/index.html          # macOS
```

Локальна версія — повноцінний редактор одного вчителя: усі інструменти зошита,
автозбереження в браузері, PWA (встановлюється як застосунок).

### Варіант 2: сервер — для роботи з класом

```bash
cd server
npm install
npm start
# → http://localhost:3000 — відкрийте в себе та роздайте класу
```

**Як проходить урок:**

1. Вчитель натискає **👥 → «Я вчитель — створити сесію»** і отримує **код сесії** (6 символів)
2. **🔳 QR-код** можна вставити прямо на сторінку — учні сканують телефоном
   і потрапляють у клас за посиланням `…?join=КОД` (код вводити не треба)
3. Усі пишуть і малюють одночасно, бачачи курсори одне одного
4. Вчитель керує правами в панелі **⚙**, проводить **📊 тест-опитування**
5. Закінчили — 💾 снапшот, 🖨 друк/PDF, ⬇ експорт зошита

## 📊 Тест-опитування класу

Швидка перевірка розуміння матеріалу прямо на уроці:

1. Вчитель (**⚙/👥 → 📊 Створити опитування**) вводить питання, 2–6 варіантів, позначає правильний(і); за бажанням — таймер 15с–2хв
2. У всіх учнів вилітає вікно — кожен відповідає **один раз**, змінити не можна
3. Результати — **автоматично**, коли всі відповіли (або вчитель показує вручну / спливає таймер):
   правильний варіант підсвічений, біля кожного — відсоток та імена тих, хто його обрав
4. Кнопка **«Вставити результати на сторінку»** — підсумок стане таблицею «Учень / Відповідь / ✓» прямо в зошиті

До показу результатів відповіді приховані від інших учнів. Стартувати/завершувати опитування може лише вчитель або ведучий.

## 🔐 Права та модерація

| Що можна | Де |
|---|---|
| Глобально «лише перегляд» / дозволити редагування | Панель вчителя |
| Точкові заборони: текст / малювання / фігури / стікери / картинки / таблиці / видалення / сторінки / експорт | Панель → список інструментів |
| Заблокувати учня (персонально) | Панель → учень → 🚫 |
| Відключити учня від сесії | Панель → учень → ✖ |
| Призначити «ведучого» (може все, як учитель) | Панель → учень → ⭐ |
| Тимчасово дозволити дії після піднятої руки | ✋ → діалог дозволів (5/10/15 хв) |
| Історія версій сторінки (снапшоти) та журнал подій | Панель вчителя |

**Усі обмеження перевіряються двічі**: UI блокує кнопки з підказкою «заборонено вчителем»,
**і сервер відкидає операцію** — навіть якщо її надіслали напряму з консолі браузера.
Учень фізично може змінювати лише свої об'єкти (крім «ведучого»).

## 🌐 Розгортання сервера

### Docker (рекомендується)

```bash
cd server
docker compose up -d     # :3000, снапшоти у ./snapshots
```

### Змінні середовища

| Змінна | Типове значення | Опис |
|---|---|---|
| `PORT` | `3000` | HTTP і WebSocket порт |
| `SNAP_DIR` | `./snapshots` | папка снапшотів сесій |

### Домен + HTTPS/WSS

WebSocket потребує `wss://`, тому потрібен реверс-проксі з TLS:

<details>
<summary><b>Nginx (click to expand)</b></summary>

```nginx
server {
  server_name zoshit.example.com;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;      # ← обов'язково для WebSocket
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr; # ← для лімітів за реальним IP
    proxy_read_timeout 3600s;
  }
  listen 443 ssl;
  ssl_certificate /etc/letsencrypt/live/zoshit.example.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/zoshit.example.com/privkey.pem;
}
```
</details>

<details>
<summary><b>Caddy (TLS автоматично)</b></summary>

```
zoshit.example.com {
  reverse_proxy 127.0.0.1:3000
}
```
</details>

Після цього працює посилання `https://zoshit.example.com/?join=КОД` та QR-коди входу.

### 🛡 Захист від DDoS (вбудовано)

Сервер захищає себе сам, без зовнішніх сервісів:

| Рівень | Ліміт |
|---|---|
| HTTP-флуд | 120 запитів/IP за 10 сек → `429` |
| WS-з'єднання | 12 з одного IP, 1000 всього |
| Створення сесій | 6/IP за 10 хв, 200 сесій всього |
| Брутфорс кодів | 5 невірних входів/IP за годину |
| Повільні з'єднання | таймаути 10–20 сек (slowloris) |
| «Мовчазні» WS | закриваються через 3 хв |
| Антифлуд малювання | ~25 ops/сек і 20 курсорів/сек на учасника |

> ⚠️ Справжній **volumetric DDoS** (гігабіти трафіку) неможливо відфільтрувати в самому
> застосунку — канал забивається до вашого сервера. Для цього поставте безкоштовний
> **Cloudflare** перед доменом (WebSocket працює «з коробки»). Вбудованого захисту
> достатньо для шкільного сценарію «десятки учнів + злий бот-скрипт».

### Масштабованість

- Кожна сесія (клас) ізольована: свій документ, свої права, свої учасники
- Десятки учнів (клас-два) на найскромнішому VPS
- Сесії без активності 2+ години вивантажуються з пам'яті; снапшоти залишаються на диску
- Зберігання **у пам'яті + JSON-снапшоти**: SQLite/Redis для шкільного MVP свідомо надлишкові

```
sovezoshit/
├── shared/                  ОБЩЕ ЯДРО (обидві версії)
│   ├── core/                doc.js (модель+ops) · history.js (undo/redo) · render.js (canvas)
│   ├── tools/               tools.js (перо, ластик, фігури, текст, виділення) · insert.js
│   ├── ui/                  app.js · topbar · toolbar · pagesbar · modals · storage · start · style.css
│   ├── collab/              collab.js · collab-ui.js · poll.js (опитування) · ws-transport.js
│   ├── ai/ai.js             AI-помічник (генератор, орфографія, тести, голос)
│   ├── util.js · vendor/qrcode.js
├── local/                   ЛОКАЛЬНА ВЕРСІЯ — статика, працює з file://
│   ├── index.html · transport.js (заглушка «офлайн») · sw.js · manifest · icons/
│   └── shared/              копія ядра
└── server/                  СЕРВЕРНА ВЕРСІЯ — Node.js + ws
    ├── src/server.js        сесії, права, rate-limit, снапшоти, опитування, анти-DDoS
    ├── public/              статика (index.html + копія shared/)
    ├── views/index.html     джерело сторінки
    ├── test-smoke.js        17 груп автотестів
    ├── package.json         єдина залежність: ws
    └── Dockerfile · docker-compose.yml
```

**Принцип:** `local/` та `server/public/` містять одну копію `shared/` — код зошита не
дублюється, змінюється лише транспорт: локальна версія чесно повідомляє «офлайн»,
серверна підключається до WebSocket.

**Філософія коду:** чистий vanilla JS без збірників і залежностей на фронті,
IIFE + неймспейс `SZ.*`, єдина модель ops на клієнті та сервері, коментарі російською.

## ❓ Часті питання

**Учень закрив вкладку — прогрес зник?**
Ні. З'єднання відновиться автоматично (до 10 спроб), а за посиланням `?join=КОД` можна
увійти знову — документ сесії живе на сервері.

**Чи можна обійти заборону вчителя через консоль браузера?**
Ні. Заборонені операції відкидає сервер — «обхід» не дійде до інших учасників.

**Скільки учнів витримає сервер?**
Десятки (клас-два) на найскромнішому VPS.

**Де мій API-ключ AI?**
Тільки в localStorage вашого браузера; запити йдуть напряму в обраний ендпоінт.
Провайдер визначається за ключем автоматично: `sk-…` OpenAI · `gsk_…` Groq ·
`sk-or-…` OpenRouter · `AIza…` Gemini · `sk-`+32 hex DeepSeek; інші — режим
«Свій сервіс». Безкоштовні ключі: [console.groq.com](https://console.groq.com) ·
[aistudio.google.com](https://aistudio.google.com).

**AI працює в локальній версії?**
Так, за наявності ключа — усі чотири функції, крім генератора тестів (той запускає
опитування класу — потрібна серверна сесія).
