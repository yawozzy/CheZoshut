# 📓 ЦеЗошит — спільний шкільний зошит

Інтерактивний онлайн-зошит для школи: рисование от руки, форматированный текст, фигуры,
стикеры, изображения, таблицы, QR-коды, таймеры, AI-помощник — и главное, **спільна
робота вчителя та учнів у реальному часі** з повним контролем прав вчителя.

Продукт існує у **двох версіях зі спільним ядром коду**:

| | 🏠 Локальна | 🌐 Серверна |
|---|---|---|
| Для кого | один учитель, підготовка уроків | весь клас у реальному часі |
| Спільна робота | ні (офлайн-режим) | так: десятки учнів у сесії |
| Дані | localStorage браузера | пам'ять сервера + знімки на диск |
| Встановлення | «скачав — відкрив — працює» | Node.js або Docker на VPS |

---

## Швидкий старт

### Локальна версія (2 хвилини, без встановлення)

1. Завантажте папку `local/` (або весь репозиторій)
2. Відкрийте `local/index.html` подвійним кліком — усе працює

Для «встановлення як додаток» (PWA) потрібен будь-який статичний хостинг:

```bash
# вариант: GitHub Pages
# 1) создайте репозиторий, залейте СОДЕРЖИМОЕ папки local/ в корень
# 2) Settings → Pages → ветка main → Save
# 3) готово: https://ваш-логин.github.io — в Chrome появится кнопка «Установить»

# вариант: любой другой статический хостинг (Netlify, Vercel, свой nginx)
# просто скопируйте содержимое local/ — это статические файлы
```

> Папка `local/` самодостаточна: `index.html`, `style.css`, `transport.js`, `shared/`, `vendor/`, `icons/`, `manifest.webmanifest`, `sw.js`.

### Серверна версія (для роботи з класом)

```bash
cd server
npm install
npm start
# → http://localhost:3000 — откройте у себя и раздайте классу
```

**Як проходить урок:**

1. Вчитель відкриває сайт, натискає **👥 → «Я вчитель — створити сесію»**
2. Отримує **код сесії** (6 символів) і може вставити **QR-код підключення** прямо на сторінку
3. Учні відкривають той самий сайт, натискають **👥 → «Я учень»**, вводять код
   — *або сканують QR телефоном і входять за посиланням `…?join=КОД`*
4. Усі пишуть і малюють на спільній дошці одночасно, бачачи курсори одне одного
5. Вчитель у панелі **⚙** керує правами (див. нижче)

## Права та модерація вчителя (панель ⚙)

| Возможность | Где |
|---|---|
| Глобально «разрешить/запретить редактирование» (режим только просмотр) | Панель → переключатель |
| Точечные права: текст / рисование / фигуры / стикеры / картинки / таблицы / QR / таймеры / удаление / страницы / экспорт | Панель → список инструментов |
| Заблокировать конкретного ученика (персонально) | Панель → ученик → 🚫 |
| Отключить ученика от сессии | Панель → ученик → ✖ |
| Назначить «ведущего» (может всё, как учитель) и снять | Панель → ученик → ⭐ |
| История подключений/отключений и действий | Панель → журнал |
| Снапшоты: сохранить версию страницы и откатить «как было 5 минут назад» | Панель → история версий |
| **Тест-опрос класса**: вопрос + варианты, все отвечают на своих экранах, потом видно правильный ответ и кто что выбрал | Панель → 📊 Створити опитування |

**Все ограничения проверяются дважды:** кнопки в UI блокируются с подсказкой
«запрещено учителем», И сервер отклоняет операцию, даже если её отправили напрямую
из консоли браузера. Ученик физически может менять только свои объекты (кроме «ведущего»).

**Антифлуд:** сервер ограничивает ~25 операций/сек и 20 курсоров/сек на участника.

## Можливості зошита (обидві версії)

- **Тетрадь во весь экран**: страница занимает всю ширину, инструменты — узкая панель **справа**
- **Бесконечная лента страниц**: листаете вниз — новая страница создаётся сама; вверх — пустая лишняя убирается; внизу индикатор «📄 N / M» (клик — переход к любой странице)
- **Живой предпросмотр**: линия/фигура видны на экране ещё в момент рисования, а не после отпускания мыши
- **Свойства только текущего инструмента**: выбрали перо — настройки пера; фигуру — форма/цвет/заливка; текст — шрифт/размер; выделили объект — его свойства
- **Настройки ⚙ сверху**: формат страницы (линейка/клетка/пропись/чистый), дублирование/удаление страницы, экспорт/импорт файлов, PNG страницы, печать/PDF, ваше имя
- **Перо** (плавное сглаживание), **ластик**, **фигуры** (прямоугольник, овал, треугольник, линия, стрелка — с заливкой), **перемещение и изменение размера** любых объектов
- **Текст**: жирный, курсив, подчёркнутый, зачёркнутый, надстрочный/подстрочный, выравнивание, цвета, печатный/рукописный шрифт, размер
- **Вставка ➕**: изображения (файл, drag&drop, Ctrl+V из буфера), стикеры 5 цветов, таблицы с редактором, круговые таймеры; QR — сразу с кодом комнаты (п. ниже)
- **Undo/Redo** (Ctrl+Z / Ctrl+Shift+Z), включая действия со страницами
- **Автосохранение** в браузере; экспорт блокнота в файл `.json`, импорт, экспорт страницы в PNG, печать/PDF
- **Масштаб**: колесо мыши, пинч на телефоне, Ctrl+0 — «вписать страницу»
- **AI-функции** (✨ вверху): помощник-генератор контента (вставляет текст прямо на страницу), проверка орфографии (выдели текстовый объект — AI исправит и заменит), генератор тестов (AI придумает вопрос и сразу запустит тест-опрос класса), голосовой ввод (Web Speech API). Подключается **свой API-ключ** — провайдер определяется автоматически по ключу (OpenAI, Groq и Gemini бесплатно, OpenRouter, DeepSeek); для любых других сервисов — режим «Свій сервіс» (OpenAI-совместимый эндпоинт). Ключ хранится только в вашем браузере, запросы идут напрямую в выбранный эндпоинт
- **Тест-опросы класса** (📊 в панели учителя, серверная версия): вопрос + варианты, ученики отвечают на своих экранах, после завершения видно правильный ответ и кто какой выбрал; итог можно вставить на страницу таблицей
- **Совместная работа** (серверная версия): синхронизация всех участников в реальном времени, курсоры с именами и цветами, «рука поднята» ✋, восстановление сессии после обрыва

## Тест-опитування класу 📊

Швидкий спосіб перевірити розуміння матеріалу прямо на уроці:

1. Вчитель у панелі **⚙/👥 → 📊 Створити опитування** вводить питання, 2–6 варіантів
   і позначає правильний (можна кілька — перемикачем «кілька правильних»), за бажанням — таймер (15с–2хв).
2. У всіх учнів одразу вилітає вікно опитування. Кожен відповідає **один раз**, змінити відповідь не можна.
3. Коли всі відповіли — **результати показуються автоматично**: правильний варіант підсвічений,
   поруч з кожним варіантом — смужка з відсотком і список імен з кольорами учнів, які його обрали.
   Результати також можна показати вручну («Показати результати») або дочекатись кінця таймера.
4. Вчитель може вставити підсумок на сторінку зошита кнопкою **«Вставити результати на сторінку»** —
   це буде таблиця «Учень / Відповідь / ✓», звичайний об'єкт зошита (переміщується, входить у експорт).

До reveal відповіді учнів приховані від інших (сервер не розсилає чужий вибір), відповідати може кожен окрім
заблокованих; стартувати/завершувати опитування може лише вчитель або ведучий. Опитування живе на сервері —
учень, що перепідключився посеред опитування, побачить його стан у welcome. Працює тільки в серверній версії.



Кнопка **👥 → 🔳 QR-код** сразу показывает окно с QR **по коду вашей комнаты** — ничего вводить не нужно: QR строится по ссылке `https://ваш-сервер/?join=КОД`. Рядом — сам код крупным шрифтом и кнопки «копировать ссылку» / «вставить QR на страницу». Ученики сканируют QR телефоном и попадают в класс.

### Защита от DDoS и флуда (встроено)

Сервер сам защищает себя на четырёх уровнях, без внешних сервисов:

| Уровень | Лимит | Что делает |
|---|---|---|
| HTTP-флуд | 120 запросов/IP за 10 сек | отвечает `429 Too Many Requests` |
| WS-соединения | 12 одновременно с одного IP | лишние закрываются (класс за школьным NAT помещается) |
| Создание сессий | 6 новых сессий/IP за 10 мин | бот не может плодить тысячи «классов» и жрать память |
| Брутфорс кодов | 5 неверных входов/IP в час | соединение закрывается без подсказок |
| Пределы сервера | 1000 WS / 200 сессий всего | при исчерпании новые отклоняются — живые продолжают работать |
| Медленные соединения | таймауты 10–20 сек | slowloris-атаки не висят вечно |
| Молчащие WS | 3 мин без сообщений | «зомби»-соединения закрываются |

Плюс на уровне участников: ~25 ops/сек и 20 курсоров/сек (антифлуд рисования).

> ⚠️ Настоящий **volumetric DDoS** (гигабиты мусорного трафика) невозможно
> отфильтровать внутри самого приложения — канал забивается до вашего сервера.
> Для этого включите бесплатный **Cloudflare** перед доменом (или аналог хостера):
> проксируйте DNS через CF, WebSocket там работает из коробки. Встроенной защиты
> достаточно для школьного сценария «десятки учеников + злой бот-скрипт».

### Своё доменное имя + HTTPS/WSS

WebSocket работает по `wss://` только поверх HTTPS. Стандартная схема — Nginx/Caddy как реверс-прокси:

**Nginx:**
```nginx
server {
  server_name zoshit.example.com;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;      # ← обязательно для WebSocket
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 3600s;                     # ← долгие WebSocket-соединения
  }
  # TLS-сертификат — например, от certbot:
  listen 443 ssl;
  ssl_certificate /etc/letsencrypt/live/zoshit.example.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/zoshit.example.com/privkey.pem;
}
```

**Caddy (проще, TLS автоматически):**
```
zoshit.example.com {
  reverse_proxy 127.0.0.1:3000
}
```

После этого в UI работает ссылка `https://zoshit.example.com/?join=КОД` и QR-коды для входа.

### Масштабируемость

- Каждая сессия (класс) изолирована: свой документ, свои права, свои участники
- Сессии без активности 2+ часа выгружаются из памяти, снапшоты остаются на диске
- Несколько классов = несколько кодов сессий на одном сервере, не мешают друг другу
- Хранение выбрано **в памяти + JSON-снапшоты на диск**: для школьного урока (десятки участников, тысячи объектов) SQLite/Redis избыточны и добавляют зависимость; при желании `SNAP_DIR` на диск сохраняет историю версий

## Часті питання

**Ученик закрыл вкладку — прогресс пропал?**
Нет. Соединение восстановится автоматически (до 10 попыток), а по ссылке
`?join=КОД` можно войти заново — документ сессии живёт на сервере.

**Можно ли обойти запрет учителя через консоль браузера?**
Нет. Все запрещённые операции отбрасывает сервер, «обход» не дойдёт до других участников.

**Сколько учеников выдержит сервер?**
Десятки (обычный класс/два) на самом скромном VPS. При больших нагрузках горизонтальное
масштабирование потребует общей БД — это осознанно выходит за рамки школьного MVP.

**Где мой API-ключ AI?**
Только в localStorage вашего браузера; запросы идут напрямую в выбранный вами
API-эндпоинт. Настройки: ✨ → 🔑 API-ключ. Провайдер определяется по ключу
автоматически: `sk-…` OpenAI, `gsk_…` Groq, `sk-or-…` OpenRouter, `AIza…` Gemini,
`sk-`+32 hex DeepSeek; для остальных (напр. tokenrouter) — «Свій сервіс» + адреса
OpenAI-совместимого эндпоинта. Бесплатные ключи: console.groq.com, aistudio.google.com.
